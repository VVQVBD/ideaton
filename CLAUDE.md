# Контекст проекта

Демо-платформа для идеатона (партнёр - Microsoft). Колледжи покупают лицензии Microsoft Copilot, а им не пользуются. Наша платформа делает ИИ-помощника обязательной и удобной частью учёбы.

**Роли:** преподаватель и студент. Вход раздельный: студенты на / (код игры - вход командой, или демо-вход), преподаватель на /teacher по PIN (TEACHER_PIN в .env). Переключателя ролей нет, смена через "Выйти".

**Функции:**
- преподаватель генерирует урок по теме и целям
- студент проходит урок, справа чат с ИИ-ассистентом, который подсказывает, но не даёт готовый ответ
- ассистент собирает недоработки урока в data/gaps.json
- у урока есть конспект (lesson.notes: sections, terms, example): его даёт преподаватель (ИИ готовит), студент читает перед вопросами, есть выгрузка в Word
- по уроку формируется Word-отчёт для преподавателя
- оценки выгружаются в Excel
- есть ежемесячный рейтинг студентов
- открытый урок (server/game.js, контент в server/game-content.js): команды, квиз по прошлой теме, урок l7 с копилотом, квест из 8 замков, итоги. Одна игра за раз: локально data/game.json, на Vercel Upstash Redis (server/game-store.js, каждая команда отдельным ключом). Токен преподавателя подписан PIN (HMAC), без хранения на сервере. Экраны опрашивают сервер раз в 1,5 с

**Разделы:** Главная, Уроки, Курсы, Рейтинг.

**Стек:** HTML/CSS/vanilla JS (public/), Node.js + Express (server.js, server/), данные в JSON-файлах в data/, ИИ Gemini через HTTP (запасной вариант openai), пакеты docx, exceljs.

**Правила:**
- ключ API только в .env на сервере (GEMINI_API_KEY, модель GEMINI_MODEL); провайдер в AI_PROVIDER
- режим MOCK_AI=true отдаёт заготовленные ответы без обращения к API
- интерфейс на русском и казахском (переключатель, тексты в public/i18n)
- код простой, с короткими комментариями на русском, так как автор учится
- не усложняй архитектуру
- в текстах использовать обычный дефис "-", а не длинное тире

**Дизайн:** "Сочный нео-брутализм": плоские цвета --blue #2B3BFF, --lime #D4FF3A, --coral #FF5A36, --yellow #FFC700, --ink #111111 на кремовом #FFF8EC, зерно на заливках. Рамки 2px, жёсткие тени без размытия (6px 6px 0), блоки скруглены 28px, кнопки-таблетки "вдавливаются" и заливаются цветом изнутри, повёрнутые стикеры. Главная: синий блок с огромным приветствием (имя на лаймовой подложке), бегущая строка, bento из ячеек разного цвета и размера. Меню - чёрный блок, панель Copilot - синий. Шрифты (локально, public/vendor/fonts): Unbounded - заголовки на русском, Onest - заголовки на казахском (в Unbounded нет казахских букв, переключение по <html lang>), Literata Italic - слово курсивом в заголовках, Golos Text - текст, JetBrains Mono - метки капсом. Стили mobile-first: база для телефона в style.css, планшет и компьютер через min-width в fx.css; bento перестраивается по ширине центральной колонки (container queries). Без градиентов-переливов, стекла, неона, блобов, эмодзи. Боковые поля страницы до 200px (--side). Светлая тема по умолчанию и тёмная (чёрный фон, кремовые рамки, лаймовые тени). Раскладка на компьютере: левое меню, центр, справа панель Copilot.

**Формула рейтинга:** баллы = средняя оценка за месяц x 0,7 + активность x 0,3; активность = min(100, пройденные уроки за месяц / 5 x 100).

**Запуск:** npm start, сайт на http://localhost:3000. Сброс демо-данных: кнопка в интерфейсе или POST /api/reset.

**Тесты:** npm test (Vitest: unit в tests/unit, компонентные в tests/component через jsdom и Testing Library), npm run test:coverage, npm run test:e2e (Playwright в установленном Microsoft Edge: сценарии, скриншоты 375/1440, axe). Тесты работают на временной копии данных (переменная DATA_DIR), data/ не трогают. После намеренной правки дизайна эталоны скриншотов обновляются командой npm run test:e2e:update. Чистые функции интерфейса лежат в public/js/utils.js (window.U), их и проверяют unit-тесты.

**Анимации:** GSAP и canvas-confetti лежат локально в public/vendor (работает без интернета). Все эффекты в public/js/fx.js и public/css/fx.css, вызываются из app.js через fx('имя'). Обязательно уважать prefers-reduced-motion. Заголовки появляются по словам из-под маски, ячейки bento - с пружиной, числа набегают; бегущая строка ускоряется и меняет направление при прокрутке; главная кнопка (.btn.cta) магнитная; курсор-стикер на блоках с data-cursor (только мышь); стикеры с data-parallax едут при прокрутке.
